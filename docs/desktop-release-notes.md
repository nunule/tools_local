tools local 是一个在本机处理图片的工具箱，包含图片水印、隐私遮挡、照片信息清理、截图隐私处理和证件副本。

支持批量导出、JSON 配置和系统“另存为”对话框。安装后可以离线使用。

### 下载与安装

请在下方 **Assets** 中选择与你的系统和芯片对应的安装包：

- `macos-arm64.dmg`：Apple Silicon Mac，macOS 13.3 及以上。
- `macos-x64.dmg`：Intel Mac，仅在提供该文件时可用。
- `windows-x64.exe`：Windows 10 / 11，64 位。
- `linux-x64.AppImage`：Linux，仅在提供该文件时可用。

实际文件名还包含版本号与内容哈希。打开 DMG 后将应用拖入 Applications；Windows 打开 EXE 后按向导安装。`manifest.json` 提供安装包版本、大小和 SHA-256。
