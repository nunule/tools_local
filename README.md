# tools local — 本地图片水印工作室 (Local Image Watermark Studio)

专为注重隐私、零网络上传打造的高性能端侧本地图片水印处理工作台。

---

## 🌟 核心特性与亮点

1. **100% 浏览器端本地渲染 (Local-First & Offline)**
   - 文件完全在浏览器端通过 `FileReader` 与 `HTML5 Canvas 2D` 处理，无任何服务端上传，断网飞行模式亦可完整使用。
   - 彻底杜绝身份证件（实名认证、租房、入职）、发票合同及商业机密文档上传泄密的风险。
   - 导出时天然抹除相机原始敏感 EXIF 与 GPS 地理信息。

2. **专业级白色半透明水印与多维微调**
   - **文字与多行排版**：支持多行文字换行，支持 `{{date}}`、`{{time}}`、`{{filename}}` 等动态宏变量一键注入。
   - **字号与粗细**：12px ~ 160px 无级缩放，细体/常规/粗体/极粗快速切换，字间距与行间距精确调节。
   - **方向与角度**：-180° ~ 180° 无级旋转调节，内置 -45°、-30°、0°、30°、45°、90° 常用快捷预设。
   - **透明度控制**：0% ~ 100% 任意调节，默认采用优雅的 45% 透白防盗防伪水印。
   - **双重防伪增强（描边与阴影）**：
     - **智能轮廓描边 (Stroke)**：即使在纯白背景照片上，白色文字依然轮廓分明、清晰可读。
     - **立体投影阴影 (Shadow)**：可调节模糊半径及 X/Y 偏移，杜绝水印与背景混色。
     - **色彩混合模式 (Blend Mode)**：支持滤色 (Screen)、叠加 (Overlay)、差值 (Difference)、柔光等。

3. **双重排布模式**
   - **全屏防伪平铺 (Tiled Repeat)**：支持水平间距 (Gap X)、垂直间距 (Gap Y) 独立调节，独创 **50% 错位交错砖墙排布 (Stagger Brick Layout)**，防裁剪与防抹除能力极强。
   - **九宫格单点定点 (Single 9-Grid)**：左上、中上、右上、居左、正中、居右、左下、中下、右下 9 种锚点，配合自定义 X/Y 偏移量，完美适配摄影角标与版权印章。

4. **交互式画布工作台**
   - **平移与无级缩放**：滚轮缩放、鼠标左键拖拽平移、双击居中、100% 原始比例与自适应一键切换。
   - **按住对比 (Hold to Compare)**：按住随时无缝对比原图与加水印后的效果。
   - **透明棋盘网格**：随时切换棋盘格背景以检查透明底图。

5. **多图批量处理与一键 ZIP 打包**
   - 底部胶卷缩略图条 (Batch Filmstrip)，支持拖拽导入、剪贴板粘贴 (`Cmd/Ctrl + V`)。
   - 统一配置一键批量并发应用，使用 `JSZip` 极速打包下载全部图片。

6. **CodeMirror 6 JSON 脚本与模板配置**
   - 集成 CodeMirror 6 编辑器，水印参数实时双向同步为 JSON。
   - 支持开发者直接编辑 JSON 配置、导入导出预设模版。

7. **PC 桌面版与深浅主题**
   - 支持一键切换 PC 桌面客户端窗体框架 (Titlebar、交通灯按钮)。
   - 支持随时切换暗黑 (Dark) 与明亮 (Light) 界面风格。
   - 支持常用快捷键 (`Cmd/Ctrl+S` 快速保存、`Cmd/Ctrl+/` 查看快捷键等)。

## 🛠️ 技术选型表

| 层面 | 使用技术 | 作用 |
|---|---|---|
| **前端框架** | **React 19、TypeScript** | 响应式组件树、高并发渲染与严格类型安全 |
| **构建工具** | **Vite 6** | 秒级热更新、Rollup Code-splitting 分块打包 |
| **界面与样式** | **Tailwind CSS 4、shadcn/ui 设计规范** | CSS 变量主题驱动、精细滑块与开关组件 |
| **状态管理** | **Zustand 5** | 轻量化集中管理图片队列、水印参数及持久化 |
| **路由切换** | **Wouter** | 极轻量客户端路由与页面组织 |
| **代码编辑器** | **CodeMirror 6** (`@uiw/react-codemirror`) | JSON 实时编辑、语法高亮与校验 |
| **自动化测试** | **Vitest、Testing Library、Playwright** | 单元测试、UI 组件测试、端到端自动化测试 |

## 🚀 启动与使用指南

### 安装依赖
```bash
npm install
```

### 启动本地开发服务
```bash
npm run dev
# 访问 http://localhost:3000
```

### 运行自动化测试 (Vitest)
```bash
npm run test
```

### 生产打包构建
```bash
npm run build
```

## ⌨️ 快捷键支持

| 快捷键 | 功能 |
|---|---|
| `Cmd/Ctrl + V` | 直接从系统剪贴板粘贴截图或图片 |
| `Cmd/Ctrl + S` | 快速导出保存当前已加水印图片 |
| `滚轮 (Wheel)` | 画布平滑缩放 (10% ~ 400%) |
| `鼠标左键拖拽` | 平移移动高分辨率大图画布 |
| `对比按钮 (C)` | 按住临时对比原始无水印图像 |
| `Esc` | 关闭当前弹出的快捷键或配置模态框 |
